Module 1: Introduction To HTML

1.1 HTML Structure

  • What is html structure ? 
    •     HTML structure contain elements each element have starting tag, content, closing tag, and some times the starting tag have some attributes.
    ex. 
        <tag attribute1="">
            some content here    
        </tag>
  • What are the main tags in HTML
    •     <!DOCTYPE html> : this is important to let the browser know which document type are you using , for exmple we use it with html to let the broswer know that we are using html5 so it switch to html5 mode
    <html> : this is the tag that contains all other tags and it should be typed once
    <head> : this tag contains metadata such as links to CSS files , the title shows on the tab , etc. and this tag well not contains to be rendered tags
    <body> : this tag contains the to be rendered tags that well be visible in the screen
  • ex:
    •     <!DOCTYPE html>
    <html lang="en">
       <head>
            <meta charset="UTF-8">
            <meta name="viewport" content="width=device-width, initial-scale=1.0">
            <title>example</title>
        </head>
        <body>
           <h1>This is an example</h1>
        </body>
    </html>

1.2 HTML Elements / Attributes

  • What are HTML elements?
    •     Elements in html are like telling the browser to render this section in a certain way (tags) with extra functionality (attributes) with a certain content.
  • What are HTML attributes?
    •     Attributes are like specifing some extra functionality to a tag , like for anchors where should they go , should it open new tap or on the same tap , and for pic/video it can specify the width and height for them.
