Module 4: HTML5 Forms & User Input

4.1 Input Types

  • HTML input types:
    •     - text : <input type="text"> Creates a text field. 
    - password : <input type="password"> Hides input characters. 
    - email : <input type="email"> Requires email format. 
    - number : <input type="number"> Only allows numbers. 
    - date : <input type="date"> Opens a calendar box. 
    - radio : <input type="radio"> Choose only one option. 
    - checkbox : <input type="checkbox"> Check multiple options. 
    - file : <input type="file"> Uploads local files.

4.2 Form Elements

  • HTML form elements:
    •     - label : <label> Adds a label to form controls. 
    - select : <select> Creates a dropdown menu. 
    - textarea : <textarea> Creates multi-line text input. 
    - button : <button> Creates a clickable button. 
    - fieldset : <fieldset> Groups related elements together. 
    LegendContent
    
    - legend : <legend> Adds a title to a fieldset. (See example box directly above)
    - datalist : <datalist> Suggests options for an input. 
    - option : <option> Defines an item inside a select box. (See select menu or optgroup list)
    - optgroup : <optgroup> Groups related options in select menu.

4.3 Form Attributes

  • HTML form attributes:
    •     - action : where should the form data be sent when pressing submit.
    - method : what is the method used to send form data, like GET or POST.
    - target : where should that link open? in the same tab , new tab? "_blank" means new tab.
    - autocomplete : tells the browser to automatically fill the inputs based on user history or not.

    ex:
    <form action="/submit-form" method="POST" target="_blank" autocomplete="on">
        <label>Name:</label>
        <input type="text" name="username">
        <button type="submit">Submit</button>
    </form>

4.4 Input Attributes

  • HTML input attributes:
    •     - value : <input value="text"> sets the default text inside the field. 
    - readonly : <input readonly> makes input text uneditable but you can still select it. 
    - disabled : <input disabled> locks the field completely so you cant press on it. 
    - size : <input size="10"> changes the width of the input box. 
    - maxlength : <input maxlength="4"> limits how many letters you can type inside it. 
    - min / max : <input min="1" max="5"> sets the limits for a number or date. 
    - multiple : <input multiple> lets you upload more than one file at once. 
    - placeholder : <input placeholder="..."> gives a faint hint text inside the field before you type. 
    - required : <input required> forces you to fill the field before you can submit the form.

Module 5: HTML5 Attributes, Block/Inline, and Semantics

5.1 Common Attributes

  • Common tags
    •     - href : where should you be navigated to when pressing on a link.
    - src : give me the file path to display a picture or a video.
    - width : changes the width of the element on screen.
    - height : changes the height of the element on screen.

5.2 Block vs Inline

  • What is <div>?
    •     <div> is a block-level element used as a container to group large sections of code or layout together.
  • What is <span>?
    •     <span> is an inline-level element used as a container to group or style small pieces of text inside a sentence.
  • ex:
    •     Here is how <div> and <span> boxes look on screen:

5.3 Semantic HTML

  • What are structural tags?
    •     - <header> : top section of the page for titles and logos.
    - <nav> : section that contain the navigation links.
    - <section> : groups standalone topics together.
    - <article> : content that makes sense on its own like blog posts.
    - <aside> : side content that is weakly related to the page.
    - <footer> : bottom section for copyright or contact info.

    ex layout:
    <header> <nav>Links</nav> </header>
    <main>
        <section>
            <article>Content here</article>
        </section>
        <aside>Sidebar</aside>
    </main>
    <footer>Footer details</footer>

5.4 Accessibility and Readability

  • Why semantic HTML is important?
    •     It gives meaning to the code layout so developers can understand the page structure instantly without reading messy code.
  • What are the accessibility benefits?
    •     It helps search engines (SEO) rank your page better and lets screen readers read your site out loud correctly for blind users.
