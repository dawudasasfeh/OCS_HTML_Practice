Module 1: Introduction To HTML

1.1 HTML Structure

  • What is html structure ? 
    •     HTML structure contain elements each element have starting tag, content, closing tag, and some times the starting tag have some attributes.
    ex. 
        <tag attribute1="">
            some content here    
        </tag>
  • What are the main tags in HTML
    •     <!DOCTYPE html> : this is important to let the browser know which document type are you using , for exmple we use it with html to let the broswer know that we are using html5 so it switch to html5 mode
    <html> : this is the tag that contains all other tags and it should be typed once
    <head> : this tag contains metadata such as links to CSS files , the title shows on the tab , etc. and this tag well not contains to be rendered tags
    <body> : this tag contains the to be rendered tags that well be visible in the screen
  • ex:
    •     <!DOCTYPE html>
    <html lang="en">
       <head>
            <meta charset="UTF-8">
            <meta name="viewport" content="width=device-width, initial-scale=1.0">
            <title>example</title>
        </head>
        <body>
           <h1>This is an example</h1>
        </body>
    </html>

1.2 HTML Elements / Attributes

  • What are HTML elements?
    •     Elements in html are like telling the browser to render this section in a certain way (tags) with extra functionality (attributes) with a certain content.
  • What are HTML attributes?
    •     Attributes are like specifing some extra functionality to a tag , like for anchors where should they go , should it open new tap or on the same tap , and for pic/video it can specify the width and height for them
  • ex:
    •     Google
    <a href="https://www.google.com/" target="_blank">Google</a>
    element: The whole line.
    starting tag: <a href="https://www.google.com/" target="_blank">.
    attributes : href="https://www.google.com/" target="_blank".
        href : it stands for hyperlink refernce, which means where should you be navigated to when pressing on Google.
        target : it means where should that link open? in the same tap , new tap? "_blank" means new tap.
    content : Google.
    closing tag : </a>.


    
    <img src="image.png" alt="This is a horse image" id="horse-image" class="image">

    element: The whole line.
    starting tag: The whole line becasue this is a self closing tag
    attributes : href="https://www.google.com/" target="_blank".
        src : what is the src path? like give me the file path to display it.
        alt : what should be displayed if the image couldnt be fetched? (a fallback string).
        id : this is helpful to style the element using CSS , it is unique.
        class : this is also helpful to style the element using CSS , but it isnt unique, you can use it for multiple elements
    content : the image it self (no other content)
    closing tag : this is a self closing tag

1.4 HTML Paragraphs

  • What is HTML paragraph
    •     HTML paragraph contains the true content inside the page unlike the headings it doesnt help the SEO to understand the importance, it display the content and thats it, also it is a Block-Level which means it takes the full width of the screen and it start a new line before and after to make the content on a line by it self
  • How to make a new line inside the paragraph
    •     We can use <br> tag to make a new line inside a paragraph just like "\n" in programming languages, also it is a self closing tag so no need for </br>
  • ex:
    •    "<p>This is <br> a paragraph</p>" will look like this:

1.5 HTML Text Formatting

  • What are the formatting types?
    •     HTML have formatting types like bold, italic, strok out, underline  and the tags like <b> for bold, <strong> for bold, <i> for italic, <em> for italic
  • So what is the difference between <b>, and <strong> if they are both for bolding a text?
    •     The difference is HTML have a semantic tags and non-semantic tags, the main difference between them is are the tag meaningful to developer (with no previous knowledge) and SEO? if yes it is semantic like <strong> and <em> if no it is non-semantic like <b> and <i> do you see how <b> is just like b so it isnt meaningful
